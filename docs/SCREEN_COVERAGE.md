## إضافات محلية غير مرصودة بالكامل

إنشاء الإعلان تعذر في فحص APK السابق بسبب تعطل المحاكي الأصلي، والحساب الداخلي طلب الدخول. توسعة Offline الحالية لا تعني أننا شاهدنا تلك الرحلات كاملة في APK. الإضافات موضّحة كـ**Demo-Ergänzung**:

- Merkliste / Suchaufträge مع الحفظ المحلي واستعادة جميع فلاتر البحث.
- Meins وتحرير اسم Demo والإعلانات المحلية والخروج.
- محرر كامل محلي: صور متعددة من الجهاز أو عينات مضمنة، ترتيب/غلاف، عرض/طلب، تصنيف وخصائص، سعر ثابت/VB/مجاني، مكان وشحن، مسودة، معاينة ثم تأكيد إنشاء/تعديل. إدارة فعال/محجوز/مباع/حذف.
- الرسائل والكتابة المحلية المحفوظة والرد الوهمي، الأرشفة والقراءة والحظر والإبلاغ المحلي والإشعارات المحلية القابلة للحذف.
- متابعة البائعين وسجل المشاهدة وتنبيه البحث المحفوظ عند إنشاء إعلان مطابق محليًا.
- نوع الملف والتفضيلات المحلية، حدود الاسترداد والتخزين، تحذير فشل الحفظ وإعادة المحاولة وإعادة الضبط المؤكدة.
- الخطوة الثانية للدخول وإتمام التسجيل التجريبي.
- مقالات المساعدة ونماذج Feedback والإبلاغ وصفحة Pur.
- النصوص القانونية والعناوين ومعلومات البائع كلها وهمية.

## التحقق التفاعلي المنفذ

جولة Web على `717d4a6` اختبرت رحلة الضيف والدخول المحلي والملف، استيراد صورة من الجهاز، المسودة واستعادتها بعد reload، المعاينة والنشر المحلي والتعديل وحالات الإعلان والحذف، البحث المحفوظ والتنبيه والمفضلة والمتابعة والسجل، المحادثة والأرشفة والحظر والإبلاغ، الإشعارات والثيم وإعادة الضبط. هذه اختبارات استخدام للنسخة المحلية، وليست مقارنة بصرية شاملة مع الأصل.

على `c01b2f3` بُني APK جديد وWeb جديد. جولة Android اختبرت استيراد JPEG ثم Android Back وحفظ المسودة والعودة إلى Meins دون فقدان شريط التنقل، واستعادة العنوان والصورة بعد force-stop وإعادة الإطلاق والدخول المحلي. نجحت المعاينة والنشر المحلي والبحث الدقيق والتعديل والحجز والبيع وإعادة التفعيل وإلغاء/تأكيد الحذف؛ كذلك الرجوع من محرر نظيف والاستمرار والتحرير مع تجاهل التغييرات، ومحادثة محلية وإعداد الثيم الداكن. أضيفت اختبارات رجوع تمنع إزالة المسار الجذري بالخطأ.

أعادت جولة Web المركزة على `c01b2f3` فحص محدد الصور وحفظ المسودة عند تبديل التبويب واستعادتها بعد reload، والشريط السفلي بسطر واحد عند 320 و393 بكسل في الثيم الداكن. سجلا CDP المحفوظان للجولتين احتويا 22 ثم 44 طلب HTTP، جميعها إلى localhost، وطلب blob محلي في الجولة الأخيرة؛ لم يُسجّل loadingFailed أو استجابة HTTP بحالة 400 فأعلى. هذا وصف للطلبات الملتقطة فقط، لا إثبات لكل مسار أو متصفح.

التحقق الآلي للشفرة المصححة: 175 اختبارًا ناجحًا تحت Dart VM، والتحليل والتنسيق ناجحان؛ حالات Chrome الخاصة بالثيم وIndexedDB والتفضيلات مغطاة أيضًا في CI. لم تتغير صور golden المرجعية لإخفاء الفروق.

## الحدود المتبقية

- نموذج محلي واحد، لا صلاحيات/حماية حسابات أو تشفير بيانات شخصية أو backend أو تعدد أجهزة.
- لا خدمات نشر/رسائل/Push/Email/Modération/دفع/توصيل. حالة Versand وnewsletter وemail preference مجرد بيانات محلية.
- التخزين async best-effort وليس معاملات عابرة لمخزن JSON والصور ولا ضمان نجاة من انهيار النظام/حذف المتصفح/إلغاء التثبيت. الأخطاء تُعرض، ولا يُنصح ببيانات حساسة.
- لا كاميرا أو GPS أو خرائط حقيقية، لا فلاتر جغرافية دقيقة أو روابط مشاركة عميقة حقيقية.
- Web يحتاج تحميل موارد كامل أولًا؛ لا ادعاء تثبيت PWA أو بدء بارد من Origin جديد بلا اتصال.
- APK موقّع debug للتجربة؛ لا جاهزية متجر أو اكتمال قانوني أو مراجعة أمن/إتاحة إنتاجية.
- Android اختُبر على محاكي باستخدام swangle وتعطيل Impeller عند الإطلاق؛ لم يُتحقق من التشغيل الافتراضي أو هاتف فعلي. لا ادعاء تحقق كل شاشة على الجهاز أو مطابقة 100%، ولا تغطية جميع المتصفحات أو مراجعة إتاحة كاملة.

## فروق مقصودة

- صور وخط بديلان مرخّصان ورسومات جديدة، دون صور إعلانات حقيقية أو أصول مستخرجة.
- الألمانية وLTR والبنية والألوان والمسافات، دون ادعاء مطابقة بكسلية مطلقة.
- التصنيفات دون عينات تعرض الحالة الفارغة.
- الخريطة والمسافات محاكاة وليست إحداثيات حقيقية.
- تغيير التصنيف **يحافظ على السعر**، رغم أن المرجع فقده أثناء إحدى التجارب.
- إعادة المحاولة في Lösungscenter تفتح المساعدة محليًا؛ المرجع بقي في الخطأ.
- النصوص القانونية والروابط أمثلة محلية واضحة، لا مواقع رسمية أو وثائق معتمدة.
- لا دفع أو اتصالات هاتفية أو رسائل خارجية أو نشر إعلانات أو Backend.
